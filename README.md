# OIBSIP-CyberSecurity-Task10-NetworkSecurityReport-
# Task 10 – Full Network Security Assessment

This repository contains the report and evidence for the authorized local/test-network security assessment required for Task 10.

## Required Files

```text
network_security_assessment.md
nmap_results.txt
wireshark_capture.pcap
```

## Tools

- Nmap – host, port, service and OS reconnaissance
- Wireshark – network traffic capture and analysis
- Nikto – web vulnerability scanning where an authorized web server is present
- Markdown – final report

## Important

The scan output and packet capture must be generated from the actual authorized test network. Do not submit fabricated Nmap, Wireshark, or Nikto results.
